# Cybersecurity Homelab

A segmented, reproducible security lab built on Apple Silicon — Active Directory, a hand-built Linux router/firewall, Wazuh SIEM, and a full detection-engineering loop from attack simulation to written detection to evasion attempt.

Start with the [IP plan & naming convention](00-ip-plan.md), the [network diagram](01-network-diagram.md), or the [design decisions](design-decisions.md) behind the build.

Phase-by-phase writeups are linked from the [repo README](https://github.com/tohudgins/Homelab) as they're published.
